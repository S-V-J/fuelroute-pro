## Product Description
FuelRoute Pro is a universal, real-world route fueling planner. Enter a start and finish location within the United States, and receive a driving route on an interactive map, optimal fuel stops selected for cost efficiency, and total estimated fuel cost. 

## Local Quickstart
*(To be completed in Phase 1)*
```bash
make install
make run
```

## API Overview
*(To be completed in Phase 1)*
- `POST /api/route/` - Calculate route and optimal fuel stops.
